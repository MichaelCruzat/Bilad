# TRACE — 30-second demo narration

One speaker. Six equal five-second sections. Read naturally at about 132 words
per minute; the video has no recorded narration so you can add your own voice.

| Time | On screen | Say |
| --- | --- | --- |
| 00:00–00:05 | Hero page and rotating globe | “TRACE turns NASA climate data into evidence you can inspect.” |
| 00:05–00:10 | Open Explore; show the global map | “Explore temperature and rainfall worldwide, from countries to individual grid cells.” |
| 00:10–00:15 | Search for India; camera fits the country | “Choose India to compare the reanalysis with a separate station record.” |
| 00:15–00:20 | Cursor highlights the two temperature estimates | “Stations show warming the reanalysis barely captures. That difference deserves investigation.” |
| 00:20–00:25 | Zoom in and select a land cell | “Zoom closer, select a cell, and inspect its trend and uncertainty.” |
| 00:25–00:30 | Copy the evidence link; end on the selected map | “Share the evidence, including sources and limitations, so others can review it.” |

The India example shows a MERRA-2 point estimate near +0.02 °C/decade versus
GISTEMP near +0.22 °C/decade for 1981–2024. The reanalysis trend is not
significant; the station trend is. The narration describes that mismatch
without claiming to establish its cause.

Recording: current local production build, 1920×1080, with a visible cursor
and real map interaction. Optional camera framing/fades are video effects,
not changes to the website. The selected Midnight theme is unchanged.
